IPO 종목 등록

수요3·수요5·배정 날짜는 수요1·청약 시작일 기준으로 영업일(주말·공휴일 제외) 자동 계산되어 별도 입력 없이 등록됩니다. 등록 후 날짜가 다르면 해당 일정을 선택해 "날짜 변경" 또는 "날짜 일괄 수정"으로 직접 고치면 됩니다. 상장 날짜는 비워둔 채 등록할 수 있으며, 나중에 상장 일정을 선택해 "날짜 변경"으로 입력하면 됩니다.

마감예정 업무 등록

"반복"을 선택하면 완료 체크 시 다음 마감일로 자동 이동합니다. "없음"은 1회성 마감으로, 완료 체크 후 직접 삭제(×)해야 목록에서 사라집니다. 마감일이 지나도 완료 체크 전까지는 목록에 그대로 남습니다.
